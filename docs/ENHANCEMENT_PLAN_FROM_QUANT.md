# StockMaster · 功能增强开发方案（参考量析平台）

> 基于 2026-10-18 两边代码现状制定。
> 参考：`C:\Users\lms\WorkBuddy\2026-10-17-14-20-34\quant`（量析平台，backend ~6,200 行）。
> 原则：**移植方法论而非照搬代码**——quant 是单文件脚本风格（FastAPI + 原生 JS），stockmaster 是插件化架构（FastAPI 插件 + React + Alembic + 751 项测试），移植时须适配本项目的分层（plugin → routers/services → core）、测试门槛（覆盖率 ≥80%）与「无未来函数」断言体系。
> 优先级依据：用户当前主线是**长江电力(600900)日线顶底分析跟踪**，a_core/顶底类能力最贴合，排最前。

---

## 一、能力差距对照

| 量析平台能力 | StockMaster 现状 | 差距价值 |
|---|---|---|
| **a_core 债核心综合模型**（tpcore.py：七维 250 日分位、最短板聚合、闸门、右侧确认，实测电力组底部命中 74%） | 通用技术指标 + ML 概率预测，无低波标的专用模型 | ★★★ 直接服务长江电力顶底主线 |
| **顶底识别**（turning_point.py + ZigZag 10% 拐点标注 + 顶底研究报告） | 无 | ★★★ 同上 |
| **形态识别** 12 类（W底/头肩/箱体突破/三连阳/缺口/均线排列…） | 无 | ★★ 可解释信号来源 |
| **风格识别**（style.py 六类分档 A~F + 默认首推映射） | 无 | ★★ 决定标的适用策略族 |
| **关联分析**（relation.py：60/120/250 日相关性、20 日形态相似度、Beta、共振增益验证） | 相关性分析（已有，口径较浅） | ★★ 共振确认可提升 a_core 胜率 |
| **次日操盘计划**（plan.py：方向/入场触发/ATR 止损目标/盈亏比降级/仓位） | 预警只有规则触发，无可执行计划 | ★★ 预测→行动的落地环节 |
| **概率预测·形态匹配路线**（历史 TopN 相似片段 + 同状态条件概率融合） | 仅 ML（GBDT/RF/LR）路线 | ★ 小样本下比 ML 更稳（stockmaster 自己的 AUC≈0.48 已证明 ML 路线在窄池上无效） |
| **策略版本库/基因层**（strategy_versions：族+过滤+阈值+风控，派生可追溯） + 池化评估（loop.py） | 策略配置（选股/样本/算法 JSON），无个股策略版本沉淀 | ★★ |
| **组合回测**（portfolio.py：共享资金、单票仓位上限、评分排序取前 K、净值 vs 沪深300、责任收益分解） | 单票回测（撮合引擎更严格：T+1/涨跌停/停牌） | ★★ 补组合视角 |
| **数据质量隔离层**（quality.py 读入截断 + data_audit 判据） | data-quality 体检（更全，含复权一致性） | ★ stockmaster 已领先，无需移植 |
| 卖出模式（指标止盈 BIAS/RSI + 生命线清仓 + 分批出场） | 回测出场较简单 | ★ 增强项 |

结论：**stockmaster 的数据层与工程层全面领先，差距集中在「信号可解释层」（形态/风格/顶底/计划）与「个股策略沉淀层」**。

## 二、开发方案（四期）

### 第一期：a_core 顶底模型移植（最高优先级）

**目标**：为长江电力等低波标的建立专用顶底识别与跟踪能力，与现有分析/预测插件并列。

| 任务 | 说明 | 落点 |
|---|---|---|
| ZigZag 拐点标注 | 10% 阈值拐点识别 + 窗口 `[−15, +3]` 事件标注，仅用于验证不进信号 | `core/turning_point.py` |
| 七维滚动分位特征 | 动量/位置/波动/量能/均线结构/长周期位置等，全部 250 日滚动分位（`min_periods=120`） | `core/tpcore.py` |
| 底部最短板 / 顶部共振计数 | 底部取七维分位最小值（防单维极端被平均稀释），顶部取共振计数 | 同上 |
| 闸门与右侧确认 | 板块跌幅/位置闸门（阈值上浮 10 分）；候选后 3 日内「收阳不破前低」才确认 | 同上 |
| 数据源适配 | quant 用腾讯/东财，stockmaster 已有 baostock/腾讯/新浪多源 + 前复权重建，直接复用本项目 `providers/` | 无需移植 datasource |
| 插件挂载 | 新插件 `src/stockmaster/plugins/turning/`：`GET /turning/scan`（当日候选）、`GET /turning/history/{code}`（历史顶底事件）、`GET /turning/report/{code}`（顶底研究报告数据） | 插件 + Alembic 迁移 |
| 定时任务 | 每日 17:15（预警之后）跑顶底扫描，命中「顶/底候选」走现有预警推送通道 | `jobs/` |
| 验证脚本 | `scripts/tp_validate.py` 移植：事件级去重（间隔 25 日）+ 70/30 时间切分，命中率不达 quant 实测口径（最短板≥75 命中 ~74%）则不上线 | `scripts/` |

**验收**：长江电力 2020–2026 区间回放，底部事件命中率与 quant 报告口径一致（±2pp）；无未来函数断言通过（截断未来数据后历史分位不变）。

### 第二期：信号可解释层（形态 + 风格 + 次日计划）

1. **形态识别**：12 类形态识别移植到 `core/patterns.py`，在分析页 K 线图上标注买卖点（复用 ECharts markPoint），买卖点与 a_core 右侧确认共用口径。
2. **风格识别**：六类风格分档（A 债核心/B 低波滞涨/C 稳健成长/D 高波趋势/E 情绪博弈/F 高波震荡）落 `core/style.py`；个股分析页新增「风格卡」：类型、特征对照、该用什么/慎用什么；风格为 A/B/C 时默认首推 a_core 族。
3. **次日操盘计划**：移植 `plan.py` 四模块交叉推导（方向倾向 ← 预测融合；入场触发四模式；ATR 止损目标夹逼；盈亏比 <1.5 自动降级）。输出挂到预测页新增「次日计划」卡片，并支持进每日 15:35 报告（用户现有 xlsx 报告链路可直接追加列）。
4. **概率预测·形态匹配路线**：TopN 相似片段 + 同状态条件概率融合，作为 ML 路线之外的第二条路线并列输出；窄股票池下以形态匹配路线为主展示。

**验收**：形态识别在 8 只核心池上无未来函数断言通过；次日计划的仓位/止损公式与 quant 逐字段对拍一致。

### 第三期：策略沉淀与组合层

1. **策略版本库**：新表 `strategy_versions`（Alembic 迁移）：个股策略以「基因」沉淀（策略族 + 过滤开关 + 阈值 + 风控 + a_core 子参数），支持派生版本、父链追溯；回测历史「设为个股策略」。
2. **池化评估与健康度**：移植 `loop.py` 的 evaluate/diagnose/monitor，自选页增加个股健康度与横向对比；策略复制时做本地校准。
3. **组合回测**：复用本项目回测引擎（保留 T+1/涨跌停/停牌的严格口径，优于 quant），叠加资金层：单票仓位上限、同日多信号按评分取前 K、现金记账；输出组合净值（对比沪深300/上证指数，指数数据本项目已有）+ 责任收益分解。
4. **卖出模式增强**：`sell_mode` 增加 `indicator`（BIAS20>N% 或 RSI14>N 止盈 + 收盘<生命线清仓）与 `scale_out`（首目标卖半 + 移动止损），出场优先级：止损 > 生命线 > 止盈 > 移动止损；K 线按 SL 样式标记。

### 第四期：工程收尾（穿插进行）

1. **前端**：新增页面按现有 10 页架构扩展（分析页卡片化改造优先，避免新开孤立页面）。
2. **文档**：新增 `docs/TURNING_POINT.md`（顶底口径与验证结论）与 `docs/STYLE.md`（风格分档依据），沿用本项目「诚实说明边界」的 README 风格。
3. **e2e**：Playwright 增加顶底扫描页与风格卡用例。
4. **监控**：a_core 命中率按季度滚动复评，跌破阈值在总览页告警（复用现有工作区通知通道）。

## 三、明确不做

- **不移植 quant 的 datasource/store/api 全套**：stockmaster 的多源容错、复权重建、插件架构、账号体系全面领先，只取方法论模块。
- **不移植 quant 的策略迭代闭环**：quant 自己已于 10-17 移除（变异提议/自动迭代），说明该路线收益不佳。
- **不做实盘对接、分钟线、深度学习**：与两项目共同的定位结论一致。
- **不改动现有 cjdl_daily.db / fundflow 数据底座**：顶底扫描以只读方式消费本项目库，15:35 定时报告链路保持不变。

## 四、节奏与规模

| 期 | 内容 | 依赖 | 预估规模 |
|---|---|---|---|
| 一 | a_core 顶底模型 + 插件 + 定时扫描 | 无 | ~2 周 |
| 二 | 形态 + 风格 + 次日计划 + 形态匹配预测 | 一期特征层 | ~2 周 |
| 三 | 策略版本库 + 池化评估 + 组合回测 + 卖出增强 | 一、二期 | ~2.5 周 |
| 四 | 前端收尾 / 文档 / e2e / 漂移监控 | 穿插 | ~1 周 |

每期结束跑 `make check` + `make e2e`，第一期额外跑 `scripts/tp_validate.py` 口径校验，保证与 quant 实测结论可对拍。
