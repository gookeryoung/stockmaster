# 顶底识别模型（turning 插件）口径说明

> 方法论移植自量析平台 `backend/tpcore.py`，实现于 `src/stockmaster/core/tpcore.py`，
> 端点在 `plugins/turning/`。所有结论的实测依据见量析研究报告
> （`C:\Users\lms\WorkBuddy\2026-10-17-14-20-34\quant\reports\顶底识别模型_研究报告.html`）。

## 1. 适用范围

**只做反转、不做动量**，适用于低波动、低换手、与大盘低相关的类债核心资产
（长江电力、国投电力、银行、高速、港口、核电）。这类标的 20 日动量 IC 显著为负。
通用趋势模型（analysis / predict 插件）与本模型**互补不替代**。

## 2. 分层口径

| 层 | 做法 |
|---|---|
| 数据 | 复用本项目 sync 层：不复权价为不可变基准 + 前复权整体重建 + 跳变 >25% 校验 |
| 标注 | ZigZag 10% 拐点 + 窗口 `[-15, +3]`，**仅验证用**（`scripts/tp_validate.py`），不进信号 |
| 特征 | 七维全部 250 日滚动分位（min_periods=120）：250 日位置 / 60 日乖离 / 距 250 日高点跌幅 / RSI14 / RSI6 / 布林带位置 / 波动分位 |
| 聚合 | 底部 = **最短板**（七维分位最小值）；顶部 = **共振计数**（分位 ≥90 的项数） |
| 阈值 | 底部综合分首次上穿 75（降档环境上浮至 85）进入候选，冷却 5 个交易日去重 |
| 闸门 | 板块 20 日跌幅 <−10% 或板块 250 日位置 <15 → 降档；个股 20 日跌 >25% 且创新低 → 挂起 |
| 确认 | 候选后 3 日内出现「收阳且不破前一日低点」才产生买入信号 |

**为什么底部用最短板**：等权平均会把「六个平庸 + 一个极端」的假底稀释成中等分；
量析实测（电力组 21 只，2020-08~2026-10）最短板 ≥75 命中 74%，共振计数 ≥4 只命中
57%——计数会被连续同向下跌灌满，所以底部绝不能用计数，顶部才用。

## 3. API

| 端点 | 说明 |
|---|---|
| `GET /api/v1/turning/scan?codes=600900.SH,...` | 最新顶底状态：分位明细、最短板分、共振计数、闸门、候选/确认信号（池 ≥3 只时启用池内等权板块闸门） |
| `GET /api/v1/turning/history/{code}?kind=bottom|top` | 历史顶底事件（冷却去重，只看事件首日） |
| `GET /api/v1/turning/rules` | 模型买卖口径的可读说明 |

## 4. 定时任务

交易日 **17:15**（预警扫描之后）：对默认标的池（自选股优先，上限 50 只）扫描，
命中「当日候选 / 当日右侧确认」经通知通道推送；`run_pipeline` 与设置页任务列表同步收录。

## 5. 验证

```bash
# 事件级验证（ZigZag 真值 + 70/30 时间外验证）
uv run python scripts/tp_validate.py --codes 600900.SH,600886.SH --start 2020-01-01

# 单元测试（无未来函数 / 冷却 / 右侧确认 / 闸门 / API 集成）
uv run python -m pytest tests/test_tpcore.py
```

对拍基准：电力组最短板 ≥75 头部命中率 ~74%。结果显著偏离时先排查指标口径
（RSI 平滑方式 / BOLL 标准差口径 / 复权方式）再谈参数。

### 与量析原实现的两处刻意偏离

1. **个股创新低挂起始终生效**：原实现把该判据放在板块分支内，板块指数缺失时
   挂起失效；移植后它只依赖个股自身，独立于是否提供板块指数。
2. **指标层复用本项目**：RSI 用 Wilder 平滑、BOLL 用总体标准差（与行情终端一致，
   见 `indicators/compute.py`），因此分位数值与量析略有差异，属口径统一而非偏差。

## 6. 边界如实说明

- 顶部信号**只收紧止损，不作清仓依据**：量析实测顶部信号 20 日后胜率仅 46%、
  均值仍为正，压的是尾部不是均值。
- 模型参数在窄池（电力组）标定，跨行业迁移前须重跑 `tp_validate.py`。
- 分位未就绪的起步期（前 120 日）无信号，属预期行为。
